# 质量证据 · skill-soros-reflexivity-detector（#48）

> 本文档记录参数整定、测试覆盖与开发中发现修复的缺陷，作为工具可信度证据。
> **非验收门槛、非投资建议**；案例回溯为定性核对，不代表未来表现。

## 一、参数整定（核心阈值 ≤ 8，集中于 `reflexivity.DEFAULT_CONFIG`）

| 阈值 | 值 | 含义 | 依据 |
|---|---|---|---|
| p_s1 / p_s2 | 0.5 / 1.0 | 趋势强度(≈t值)萌芽/加速门槛 | 斜率÷波动，t≈1 对应统计显著趋势 |
| fb_s2 | 60 | 加速期正反馈燃料分位门槛 | 分位制，>60=资金面强于常态 |
| hot_pctl / gap_hot | 90 / 90 | 狂热的趋势/裂口分位门槛 | 极端分位（top 10%）定义狂热 |
| fragile_pledge | 55 | **大股东质押占其持股比例**脆弱警戒线(%) | 质押 >50% 触发信披红线，55 留缓冲。**看大股东持股口径，非总股本口径**（后者常<10%，配 55% 阈值会永不触发） |
| break_dd | 0.15 | 破裂回撤门槛 | 主升浪破位经验值 |
| voldiv_break | 60 | 破裂：量价顶背离强度门槛 | 分位制；"价近高点且 20 日均量相对基准缩量"，缩量 40% 记满分 |
| fuel_drop_break | 20 | 破裂：燃料 20 日下滑门槛 | 初设 8 在真实数据上误报（宁德小幅回落即触发），收紧至 20 要求**明显退潮** |
| neg_p | −1.0 | 负反身性趋势门槛 | 对称 p_s2 |
| event_decay_days | 60 | 基本面事件新鲜度衰减 | ≈一个季度，下一次披露前 |

环型参数组（同一状态机按 loop_type 切换）：慢环 60/250 窗口、连续 5 日确认；快环 20/60 窗口、连续 2 日确认。

- **真实数据环境**（有 panda_data）：**22 项全绿**（真实拉宁德 300750.SZ、欧菲光 002456.SZ、中芯国际 688981.SH 真跑）。

覆盖：状态机确定性（boom→S2 / 负反身→S5 / **崩盘→S4 破裂** / 横盘不误报 S3 / **无回路不误报 S4**）· **交易量顶背离** · 考验 conviction · 暮色 CogF 衰减 · 快环 loop_type · 质押螺旋 fragile · **PIT as_of 无未来泄漏** · **大宗折价门槛门控** · **大股东质押口径** · 空数据/缺列/None dtype · 历史不足保护 · validate_input · run 直连 · render · 真实数据 optional。

## 三、开发中发现并修复的缺陷（测试驱动，均由 test.py 抓出）

1. **分位函数对常数序列返回 100%**（应中性）→ 改 midrank（常数→50），否则横盘时恒定换手被算成 100 分位、误触发狂热 S3。
2. **考验被锁死在 `cur==S2` 内** → 回调必然让 cur 暂时切出 S2，创新高（考验通过）时考验已被清掉，conviction 永远加不上。改为触发在 S2、跟踪与通过独立于 cur。
3. **考验触发要求精确 S2 过严** → 洗盘常在加速末段（P_acc 已转负、raw 掉出 S2）发生，改为"强趋势 P≥p_s2 中的回调"即可触发，更贴合市场语义。
4. **fragile 被无事件的 0 成分稀释**（质押 72% 却因其他负成分为 0 被加权拉到 25）→ 质押螺旋是水平型硬风险，单独触发 fragile，不被稀释。
5. **PIT 未来函数泄漏**（as_of 先算整序列再截断，cog_f/par_f 前视与 classify_loop_type 用末日泄漏未来）→ 改为**先按 as_of 截断 panel/events 再计算**。
6. **质押读错口径致脆弱预警在真实数据上永不触发**（真机实测抓出，2026-07-11）：`load_pledge` 原取 `acc_pledge_total_ratio`（总股本口径），欧菲光实测仅 ~6.9%，配 55% 阈值 → fragile 恒 false，脆弱预警形同虚设。改取 `acc_pledged_hold_ratio`（大股东质押占其持股比例，欧菲光 ~76.7%），仅计持股≥5% 的大股东（滤小股东满仓质押误报）。**修复后欧菲光 fragile 由 false→true、fb_neg 2.3→26.8**，宁德（无质押）仍 false 不误报。合成夹具（直接置 acc_pledge_ratio）掩盖了此 bug，故补 `test_pledge_holder_ratio` 假 api 离线回归。
7. **大宗折价对每笔大宗都误报**（真机实测抓出）：原 `load_corp_action_events` 对 `get_block_trade` 每一行都发 `block_discount` 事件（宁德 2.5 年 490 笔全发），而该接口**无折溢价字段**、从未判是否真折价。改为传入当日不复权收盘、只有**折价≥3%** 才计入（无收盘参照则保守跳过）。**宁德 block_discount 事件 490→77**（仅真折价）。补 `test_block_discount_gating` 离线回归。

### 🔁 artifact 实测复盘轮次（用户核心反馈"缺结论性" + 688981 中芯实测，均已修+测）

8. **【P1，用户核心反馈】`_plain_text` 是纯按 stage 查表的静态模板**（S0/S1/S3/S4/S5 零变量插值，仅 S2 例外）：GAP/Sync/CogF/conviction/confidence 都算了却不进"人话"。改为**六阶段读数插值 + 骨架分支**：S0 高GAP低Sync→"价格跑在前面、方向对不上的透支型"（中芯 GAP=62.5/Sync=33.9 实测印证）；S1 引用 conviction/in_test；S3 引用 CogF"利好不涨"；燃料 fb_long 常态化；末尾加"接下来盯什么"监控清单。测 `test_plain_text_dynamic`。
9. **【P1】confidence 从不进 plain_text、无分档**：加 `confidence_band`（<0.3低/0.3–0.6中/>0.6高）并写进人话（"本次判断把握X"）。
10. **【P2】score 无分量拆解**：analyze 输出加 `score_breakdown`（sync/fb_long/trend/dual 四分量）。测 `test_score_breakdown`。
11. **【P2】非交易日入参无显式提示**（实测 `_stock_row` 把 `trade_date` 写成入参日而非真实交易日）：改用真实交易日，加 `input_date_adjusted` 标记（周六 20260711→trade_date 20260710、adjusted=True 实测通过）。

### 🔁 对照任务清单 #48 的功能缺口复核（2026-07-21）

12. **【阻断级】S4「破裂」是死代码，永不可达**：清单 #48 明确要求识别五阶段含「破裂」，且 `DEFAULT_CONFIG` 里
    `break_dd: 0.15`（注释写"破裂：距阶段高点回撤门槛"）也在，但 **`_raw_stage()` 的 return 分支只有
    `S0/S1/S2/S3/S5`——从来没有 S4**，`break_dd` 全仓库**零引用**（触发器压根没接上）。
    连带 `position_advice="exit"` 也永不可能输出（S4 是唯一映射到 exit 的阶段），`_plain_text` 的 S4 分支是死代码，
    而 SKILL.md / 生产 SKILL.md / HTML 看板配色**都在宣称 S4 存在**。
    实测证据：造"暴涨 10 倍 → 崩盘 −60% + 融资退潮 + 顶部缩量"的标准破裂剧本，阶段序列直接
    `S0→S1→S5`，S4 出现 0 天；`test.py` 也没有任何 S4 用例（与不可达自洽）。
    **修复**：接上 `break_dd`，新增 S4 分支（详见下条口径），补 `test_rupture_stage_reachable`。
    修复后同一剧本演进为 **`S0→S1→S4→S5`**，S4 持续 18 天、`advice=exit`、回撤 25.6%。

13. **【阻断级】清单点名的「交易量顶背离」完全未实现**：#48 要求"反转信号 = 斜率背离 + 交易量顶背离"，
    斜率背离有（GAP/Sync/CogF 衰减），但 `volume` 在整个 `reflexivity.py` 里**只出现在测试夹具生成里**，
    从未参与任何判定。**修复**：新增 `vol_divergence_series()`——价近滚动高点（≥0.95）且 20 日均量相对
    基准缩量时给分，缩量 40% 满分。补 `test_volume_top_divergence`：顶部缩量→92 分，价量齐升→0 分。

14. **【修 12/13 时自造的新假阳性，已修】破裂判据在真实数据上误报**：初版把 S4 写成单日独立判据
    （曾走出趋势 + 回撤≥15% + 燃料下滑≥8），真机实测 **300750.SZ 宁德时代被判 S4/exit**，
    但当时 `loop_type=none`（根本没有反身性回路）、`vol_div_peak=0`（无顶背离）、`f_slope=6.24`
    （基本面还在上修）——只因融资小幅回落 9.4 就触发，人话还宣称"回路一断会反向踩踏"，属明显过度解读。
    **根因是建模错了：破裂是「从回路里掉出来」的转移，不是单日独立判据。**
    **修复**：(a) 状态机限定只有前一阶段是 S1/S2/S3 才允许转 S4，否则落 S0；
    (b) `fuel_drop_break` 由 8 收紧到 20（须明显退潮）。
    修复后宁德回到 **S0/observe**，合成崩盘剧本仍正常出 S4。补 `test_no_false_rupture_without_loop`
    （回撤达 46% 但从未入回路 → 不报 S4）。

15. **【顺带发现，已规避】`_roll_pct_rank` 遇窗口内任何 NaN 即返回 NaN**：`P` 前 `trend_win` 天必为 NaN，
    故慢环（`pct_win=250`）的 `P_pctl` 要 **310 个交易日**历史才非 NaN，短于此则静默回落到默认值 50。
    这使得依赖 `P_pctl` 的判据在短历史下**静默失效**。本轮修复中的"破裂前曾走出趋势"因此改用 `P` 峰值
    而非 `P_pctl` 峰值，避开该陷阱。**该函数本身未改动**（会扰动既有已整定的读数），此处如实记录为已知限制。

## 四、案例回溯（定性核对，待真实数据环境补全）

方法：对公认的反身性案例，用 `backfill` 逐日回放，人工核对阶段时间线是否符合叙事：

| 案例 | 预期阶段轨迹 | 状态 |
|---|---|---|
| 高景气龙头主升浪（慢环：基本面上修×全民关注） | S1→S2→(S2T考验)→S3暮色→S4 | 待回溯 |
| AI 算力链题材（快环：涨停+龙虎榜聚集） | fast 环 S1→S2→S3→炸板 S4 | 待回溯 |

## 五、已知限制

- 不预测破裂点，只做阶段识别与仓位纪律。
- 北向个股数据 2024/08 后停披露 → 北向成分默认零权重。
- 快报覆盖不全 → F 链主用预告+财报。
- 状态机阈值为分位/经验值，不同市场环境需校准（阈值集中于 DEFAULT_CONFIG 便于整定）。
- 合成夹具验证逻辑正确性，真实收益表现需独立回测，不在本工具承诺范围内。
